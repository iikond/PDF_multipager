# PDF Multipager

Этот скрипт предназначен для объединения серии последовательно пронумерованных изображений формата BMP в один файл PDF. Идеально подходит для пакетной обработки снимков экрана или сканов, которые должны составлять одну книгу/документ.

## Как это работает?

Скрипт сканирует текущую директорию в поисках всех файлов `.bmp`. Он ожидает, что файлы будут названы по строгому шаблону: `<document_ID>_<page_number>.bmp`.

1.  **`document_ID`**: Уникальный идентификатор документа (например, `ReportA`).
2.  **`page_number`**: Порядковый номер страницы (начинается с 0 или 1, в зависимости от того, как вы их назвали).

Скрипт автоматически соберет все части одного документа вместе и сохранит результат в папку `pdf/`.

## Предварительные требования (Dependencies)

Для работы скрипта вам потребуется библиотека **Pillow** (PIL). Установите её с помощью pip:

```bash
pip install Pillow
```

## Подготовка файлов

Убедитесь, что все ваши изображения находятся в той же директории, что и `PDF_multipager.py`.

Например, для документа с ID `MyDocument`:
*   Первая страница должна называться: `MyDocument_0.bmp`
*   Вторая страница: `MyDocument_1.bmp`
*   ...и так далее.

**Важно:** Порядок страниц критически важен! Скрипт сортирует страницы по номеру, который вы указали в имени файла.

## Использование (Usage)

1.  Поместите скрипт (`PDF_multipager.py`) и все BMP-файлы в одну папку.
2.  Запустите скрипт из терминала:
    ```bash
    python PDF_multipager.py
    ```

### Результат

После успешного выполнения, вы найдете готовые PDF-документы в новой папке с именем `pdf/`. Имя файла PDF будет соответствовать `document_ID` (например, `pdf/MyDocument.pdf`).
